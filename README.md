# 📐 Flexbox Layout

A simple HTML and CSS project that demonstrates the use of **CSS Flexbox** to create a structured webpage layout. The layout consists of a header, footer, sidebar, main content area, and nested sections, making it easy to understand Flexbox positioning.

## 📌 Features

- Header and Footer Layout
- Sidebar Navigation Area
- Main Content Section
- Nested Flexbox Layout
- Simple and Colorful Design
- Beginner-Friendly Project

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox

## 📂 Project Structure

```
Flexbox-Layout/
│── index.html
│── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

## 📚 Concepts Used

- CSS Flexbox
- Nested Flex Containers
- Width and Height
- Basic Page Layout
- Background Colors
- HTML Div Structure

## 📸 Output

The webpage displays:
- Header
- Footer
- Left Sidebar
- Main Content Area
- Top Section
- Bottom Section divided into two equal parts

This project is useful for learning the basics of CSS Flexbox and webpage layout design.
